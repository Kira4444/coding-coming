## 2. 密码处理

- 密码**仅**作为 SSH MCP `ssh_connect` 的认证参数传入，未写入文件、未写入 shell 命令 argv、未回显到用户可见输出。
- 若用 CLI `ssh`，密码应走交互输入或 `SSH_ASKPASS`/凭据管理，**不要** `sshpass -p '...'`（`ps` 可见）。
- 不把密码记入 `notes.md` 明文长期存档；本文件不复述密码原文。
- 排查结束后建议用户：若密码曾通过聊天工具传递，考虑轮换；优先用密钥/堡垒机自己的二次认证。

## 3. 安全检查点（远程操作）

1. **先只读后变更**：`status` / `nginx -t` / 日志 / 磁盘全部只读。
2. **不盲重启**：未定位根因前不 `systemctl restart`、不 `kill`。
3. **变更可回滚**：改 `/etc/nginx` 前备份目录；`nginx -t` 通过再 restart/reload。
4. **影响面**：测试环境仍可能有关联服务；restart 前在回复里写明影响与回滚。
5. **越权**：若堡垒机仅授权某账号，不私自提升或改别人配置文件属主。
6. **日志内容**：access.log 可能含内网 URL/账号参数，输出给用户时只摘关键行，不整文件粘贴敏感信息。
